# EduConnect — Smart Learning Hub

Competition-oriented Android learning platform foundation.

Core backend model:
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Firebase Cloud Messaging

Current first build:
- Professional home screen
- Subject/question browsing
- Admin authorization check
- Admin publishing of questions and answers
- Firestore-backed messages
- Profile display
- Notification service foundation
- Firestore security rules

Next modules:
- Full student registration/login UI
- Private 1-to-1 chat
- Class/group chat
- Image/document/voice-message attachments
- Technical Drawing diagram viewer
- Admin upload manager
- Search, bookmarks and notifications
- User moderation
- Complete polished competition UI
